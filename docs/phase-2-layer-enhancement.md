# Phase 2 layered interaction enhancement

## Protected baseline

This enhancement preserves the accepted still-first foundation:

- six anchors and five scroll intervals;
- the existing sticky geometry and track height;
- `useJourneyEngine`, current/next still blending, resolver, scene config, focal
  tiers, orientation recovery, and reduced-motion preference;
- Corporate routes, metadata, SEO, and the non-video homepage runtime.

`timeline.ts`, scene checkpoints, `blendStart`, and scroll geometry are not
changed. Continuous interaction values remain refs/CSS custom properties; React
state still changes only at scene boundaries or on throttled diagnostics.

## Asset audit decision

The six supplied archives contain 71 safe PNG entries. Every entry is 1672×941
RGBA. Archive paths were checked before extraction and contained no absolute,
drive-qualified, or parent-traversal paths.

Every supplied base is already a completed composite. Human, city, mountain,
and sky cutouts therefore remain excluded from the runtime layer registry to
prevent doubled subjects and edge seams. Selected overlays are converted to
WebP and registered in `lib/scrollytelling/layer-config.ts`.

| Scene | Runtime strategy | Selected separated layers |
| --- | --- | --- |
| FIELD | Base + one quiet atmosphere layer | fog haze |
| ORDER | Base + ordered sparse signals | perspective grid, lake grid, nodes, city lights |
| DESIGN | Base + 2D→3D structural cues | ground lines, volumetric frames, vertical guides, design points |
| BUILD | Base + selected spatial cues + inner window | transparent frames, spatial nodes, calculation lines |
| ADOPT | Human base + restrained system traces | information overlay, grid traces, ambient glow |
| RETURN | Clean human foundation + hybrid infinity | separated skeleton, separated optical layer, existing SVG topology |

Notable exclusions include FIELD's empty water-reflection layer, duplicate
people/background layers, saturated BUILD composites, RETURN light-particle and
dot-dissolve layers with baked white blocks, and the plain white transition.

### RETURN foundation exception

The supplied completed RETURN base already contains the finished infinity and a
right-side white dissolve. The nominal background cutouts also retain enough of
those features that stacking them recreates the finished mark too early.
Therefore, the clean ADOPT endpoint is intentionally reused as RETURN's early
human/city/mountain/digital-ground foundation. It creates a continuous handoff
without a duplicate subject. RETURN's supplied skeleton/optical assets enter
only in their approved late phases, over the existing responsive SVG trace.

## Interaction timeline

RETURN remains the sixth endpoint, so its formation derives from the existing
final ADOPT→RETURN interval instead of inventing a sixth scroll interval:

```text
global .800 -> RETURN .00
global .840 -> RETURN .20
global .880 -> RETURN .40
global .920 -> RETURN .60
global .956 -> RETURN .78
global .980 -> RETURN .90
global 1.00 -> RETURN 1.00
```

The pure interaction timeline owns BUILD steps, ORDER/DESIGN phases, RETURN
boundaries, and dot progress. The same input always produces the same output,
so reverse scroll is an exact reversal rather than a second animation path.

## BUILD and RETURN rendering

BUILD adds one translucent architectural System Window inside the existing
sticky Stage. It does not create nested sticky geometry. Its six states are
Observe, Structure, Design, AI Workflow, Automate, and Output.

RETURN uses the existing horizontal, closed-loop SVG path for responsive
structure. A dotted SVG stroke forms the point-cloud phase; the selected bitmap
skeleton and optical body are masked and kept at low opacity. The SVG provides
the clean geometry, while the PNGs supply optical irregularity without becoming
a second infinity.

## Dot release and Corporate rail

RETURN 90–100% uses a CSS radial-dot field plus a progress-bound solid release.
The dark world is broken into dots before the white Corporate surface is
revealed. Supplied baked dissolve/white-fade PNGs are not used.

The first Corporate surface includes a duplicated, seamless keyword rail. It
pauses on hover, focus, or touch focus. Reduced motion disables the loop, hides
the duplicate group, and leaves a manually scrollable static row.

## Reference-video translation

The four supplied MP4s are reference-only and are not copied into `public`.
Their reusable grammar is limited to a stable outer pin, paced inner-state
changes, foreground/background separation, density reduction into ADOPT,
deterministic dot release, and a slow horizontal rail. Recorded branding,
screen layouts, copy, and sphere motifs are not used.
