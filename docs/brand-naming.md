# Brand naming rule

| Context | Approved form |
| --- | --- |
| Existing approved visual logo assets | `LOOP Innovate` exactly as drawn |
| Visible text, legal documents, page titles and metadata | `L∞P Innovate` |
| Organization structured data | `name: L∞P Innovate`, `alternateName: LOOP Innovate` |
| URLs, repository paths, filenames and code identifiers | ASCII `loop` / `loop-innovate` |
| Accessible logo text | Prefer `L∞P Innovate`; `LOOP Innovate` is an acceptable technical fallback when the infinity character is unsupported |

Do not redraw, regenerate, or silently alter the approved logo. The word `LOOP` in the image is a visual brand asset; it does not change the legal/textual name.
