# Motion Token Migration Map

Source audit result:

- **15 distinct literal tokens at 29 literal `data-motion="…"` sites**;
- **22 runtime token values** after typed props and route-derived item tokens are
  included.

This reconciles the previous 15/29 audit: it counted literal JSX attributes. The
runtime set additionally contains `split`, `scale-number`, `line`, `warm`, `story`,
`progress-item` and `line-item`, which enter through controlled component props or
the version-controlled route map.

## Common trigger contract

`CorporateMotion` marks `[data-motion]` elements with a one-shot
`IntersectionObserver`. The reference observer uses root margin
`-8% 0px -10%` and thresholds `0`, `0.12`, `0.4`; once visible, an element remains
revealed. If IntersectionObserver is unavailable or reduced motion is requested,
content is made immediately visible. Shared transition rules live in
`components/site/site.module.css`.

## WordPress boundary

- Gutenberg users must not type arbitrary `data-motion` values.
- Tokens remain an internal theme enum and are selected by fixed template/section
  variants. Unknown values fail validation and render without motion.
- Motion CSS, observer logic, route mapping, trigger thresholds, one-shot behavior
  and reduced-motion overrides are version-controlled theme assets.
- Editable content supplies text/data only; the template selects the token.
- WordPress acceptance compares all 22 runtime values, even though only 15 are
  literal JSX attributes in the Next.js source.
