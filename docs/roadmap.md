# L∞P Innovate Website v3 Roadmap

## Production direction

~~~text
Static Scrollytelling Foundation
  -> Scene Anchor Integration
  -> Overlay and Motion Polish
  -> Infinity RETURN Refinement
  -> Copy and Evidence Finalization
  -> Optional Video Reintroduction
  -> Performance and Accessibility QA
  -> Production
~~~

Six still anchors and code-driven motion are the production baseline. Optional
video may be skipped entirely without lowering the Journey acceptance standard.

## Scene Anchor Integration

Integrate:

~~~text
01-field.webp
02-order.webp
03-design.webp
04-build.webp
05-adopt.webp
06-return.webp
~~~

FIELD is extracted from the approved existing FIELD proof source. Supplied source
images map to ORDER through RETURN. For each scene:

1. preserve the approved source;
2. export the canonical WebP;
3. configure only the existing path;
4. validate signature, mapping, focal tiers, and placeholder behavior;
5. inspect Desktop, Tablet, Compact, Narrow, and short landscape;
6. approve the scene before marking it READY.

Gate: six approved anchors work without fake imagery or a nonexistent request.

## Overlay and Motion Polish

Refine chapter-specific grammar:

- FIELD minimal atmosphere;
- ORDER paths and alignment;
- DESIGN grids, planes, and geometry;
- BUILD restrained activation;
- ADOPT calm human/environmental support;
- RETURN convergence and circulation.

Calibrate blendStart, scale, parallax, blur, masks, overlay density, and contrast.
Keep state deterministic and reversible. Avoid independent narrative timers,
heavy dependencies, fake telemetry, and ornamental overload.

Gate: every chapter is meaningfully distinct, premium, readable, performant, and
complete in reduced motion.

## Infinity RETURN Refinement

RETURN alone may form a complete horizontal infinity from one interwoven
blue-to-cyan ribbon. Both elliptical loops must be closed and uncropped with a
natural front/back crossing.

Reject any center sphere, ring, capsule, bar, mechanical core, broken loop,
vertical symbol, earlier-scene infinity, or cyberpunk bloom. Use a quiet
circulation state if the compliant form is not ready.

Gate: user visual approval, responsive no-crop evidence, static reduced-motion
state, and no loss of semantic meaning when decoration is absent.

## Copy and Evidence Finalization

- Approve Journey and corporate copy.
- Add only real services, pricing scope, FAQ, contact, legal, security, privacy,
  and AI-policy facts.
- Add case studies and metrics only with verifiable evidence and publication
  approval.
- Finalize metadata and canonical origin after domain approval.

Gate: brand, factual, legal, accessibility, and content review complete.

## Optional Video Reintroduction

This milestone is optional. A video may enhance one scene only when it has an
approved creative and measured benefit. It must use the same Timeline and still
fallback, remain disabled in reduced motion, and never become required for other
scenes or for release.

Validate configured video metadata, codec, Range behavior, switching, responsive
selection, and failure fallback. Do not restore a five-video dependency.

Gate: static mode remains the baseline and passes unchanged when optional video
is disabled or fails.

## Performance and Accessibility QA

- Measure image decode, LCP, layout shift, paints, filters, masks, and any
  visibility-gated RAF.
- Confirm no nonexistent/repeated media requests or video requests in static
  mode.
- Run the complete responsive matrix, physical mobile browsers, 200% zoom,
  keyboard, screen reader, contrast, reduced motion, slow assets, Console, and
  Network inspection.
- Re-run lint, typecheck, tests, validator, and production build.

Gate: evidence is recorded with no unresolved release-blocking defect.

## Production

- Approve origin, indexing, analytics/consent, policies, monitoring, rollback,
  migration, and deployment ownership.
- Deploy only through the explicitly approved release workflow.
- Keep the existing production L∞P site unchanged until that approval.

## Never introduce

- fake production imagery, stock substitutions, case studies, metrics, or legal
  claims;
- a dependency on missing transition videos;
- unapproved Infinity imagery outside RETURN;
- GSAP, Three.js, WebGL, or particle systems without a demonstrated requirement;
- a responsive, accessibility, SEO, or corporate-site regression;
- production deployment as an implied consequence of completing this roadmap.
