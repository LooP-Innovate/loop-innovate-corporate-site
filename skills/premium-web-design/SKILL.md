# Build premium L∞P web surfaces

## Start from project contracts

Read docs/design-system.md, docs/responsive-strategy.md,
docs/static-scrollytelling-mode.md, and docs/accessibility.md. Inspect existing
tokens and primitives before adding values or components. Preserve semantic
document flow and the complete corporate site after the Journey.

## Compose deliberately

- Use restrained editorial grids, strong alignment, and purposeful whitespace.
- Keep containers coherent across Header, content, Contact, route Heroes, and
  Footer; allow only the still Stage to be intentionally full bleed.
- Prefer structured lists and split compositions over interchangeable card walls.
- Treat missing proof and imagery as an explicit state, never visual filler.
- Let RETURN release deliberately into normal corporate reading flow.

## Use still scenes

Keep six approved still anchors as the Journey baseline. Do not make Hero
readiness depend on video. Protect focal subjects and leave adequate contrast
space for copy and overlays. Keep structural graphics scene-specific and
restrained; follow the overlay grammar in static-scrollytelling-mode.md.

Only RETURN may host a compliant infinity. Follow loop-brand constraints and
omit it when a good form is not ready.

## Typography and material

Prioritize Japanese glyph quality, punctuation, line height, and measure. Reserve
display scale for Hero/Journey moments. Use mono for indices/diagnostics only.
Choose spacing, color, surface, border, radius, shadow, z-index, and motion from
tokens. Preserve visible focus.

## Responsive composition

Use the retained Wide/Desktop/Tablet/Compact/Narrow/short-landscape contract.
Tablet uses the compact dot rail; Compact hides it while retaining scene identity
and progress. Respect safe areas, 44px targets, stable 100svh Stage behavior, and
100dvh-bounded disclosures. Recheck still crop, Japanese wrapping, zoom, and
orientation.

## Validate honestly

Check hierarchy, overflow, keyboard order, focus, contrast, landmarks, headings,
reduced motion, and corporate flow. Browser-test each canonical still and
overlay; source rules alone are not responsive or visual PASS.
