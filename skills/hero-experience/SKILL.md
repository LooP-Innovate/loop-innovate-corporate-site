# Shape the FIELD LOOP Hero

## Preserve the story

Read docs/journey-architecture.md, docs/journey-asset-spec.md,
docs/static-scrollytelling-mode.md, and docs/responsive-strategy.md. Keep FIELD,
ORDER, DESIGN, BUILD, ADOPT, RETURN in that order. Keep final copy in
configuration/content and use factual development labels while pending.

The homepage is still-first. It must remain complete with zero Journey video
requests. Existing video is an extraction/regression source, not normal Hero
timing or rendering.

## Compose the first viewport

Layer a configured still or truthful placeholder, scene atmosphere, structural
overlay, motion accent, shade, copy, progress, responsive rail, navigation, and
gated Debug. Keep essential identity legible before images or JavaScript are
ready.

Use cover with Desktop, Tablet, and Mobile focal positions. Start FIELD at center,
30% center, and 25% center respectively, then calibrate against screenshots.
Apply the same focal tier to still and compatibility fallback.

## Make chapters distinct

Use minimal FIELD graphics, ORDER paths, DESIGN geometry, BUILD activation,
calmer ADOPT support, and RETURN convergence. Derive transition state from the
pure Timeline so reverse scroll reconstructs it. Avoid a plain six-image
slideshow, black gaps, or unsupported telemetry.

## RETURN and exit

Only RETURN may reveal a horizontal closed-loop interwoven infinity. Omit it
rather than rendering a sphere, ring, bar, capsule, mechanical core, broken loop,
or cropped symbol.

Let RETURN release into the Journey Exit and corporate document flow without a
pin trap or abrupt dark-to-light cut.

## Support all users

Keep visible rail buttons keyboard operable with aria-current, focus, and 44px
targets; use dot rail on Tablet and hide it on Compact/short landscape while
retaining scene identity/progress. Reduced motion uses static scenes with no
drift, parallax, masks, line drawing, continuous loops, smooth jumps, or optional
video. Do not announce continuous progress.

## Validate

Test first paint, each still and placeholder, every boundary forward/reverse,
rail jumps, RETURN-only infinity, release, all focal tiers, short landscape,
orientation progress, missing/slow images, reduced motion, keyboard, Console,
Network, and normal corporate content. Do not claim PASS from source inspection.
